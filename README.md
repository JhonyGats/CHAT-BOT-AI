# AI Chat с аутентификацией

Приложение для общения с языковыми моделями через OpenRouter API.

## Функции
- Вход по PIN-коду (генерируется при первом запуске)
- Сохранение истории чата в SQLite
- Экспорт диалогов в JSON
- Аналитика использования (токены, время ответа)
- Мониторинг производительности (CPU, память)

## Установка и запуск
1. Создайте виртуальное окружение:
   
   python -m venv venv

Активируйте его:

Windows: venv\Scripts\activate

Linux/Mac: source venv/bin/activate

Установите зависимости:


pip install -r requirements.txt

Запустите:

bash
python src/main.py
При первом запуске введите API-ключ OpenRouter. После проверки баланса будет создан PIN для последующих входов.
